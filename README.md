# PPKTP poling period 선택기

측정한 레이저의 중심 파장을 펌프로 쓸 때, type-II collinear degenerate QPM-SPDC
(pump y, signal z, idler y) 조건을 맞추는 poling period(Λ)와 결정 온도를 계산해 보여주는 웹 페이지입니다.
계산은 온도 의존 Sellmeier 식을 따릅니다.

- 빌드 과정이 없는 정적 페이지입니다 (HTML + CSS + JavaScript, 외부 라이브러리 없음).
- `index.html`을 더블클릭해서 브라우저로 열어도 그대로 동작합니다.

## 그래프 확대/축소

모든 그래프 탭 위의 **x축 범위** 슬라이더로 가로축을 확대(왼쪽)·축소(오른쪽)할 수 있습니다. 탭마다 범위를 따로 기억합니다.

| 탭 | 가로축 | 슬라이더가 조절하는 값 | 기본값 |
|---|---|---|---|
| QPM 온도 | 펌프 파장 | 레이저 파장 범위 양옆의 여백 (0.02–10 nm) | 0.3 nm |
| 후보 Λ 전체 | 펌프 파장 | 레이저 파장 범위 양옆의 여백 (0.1–40 nm) | 8 nm |
| 온도별 필요한 Λ | 결정 온도 | 오븐 사용 온도 범위 가운데 기준 반폭 (5–200 °C) | 100 °C |
| 예시 | 펌프 파장 | 403.5 nm 기준 반폭 (0.05–5 nm) | 0.5 nm |

- 슬라이더는 로그 눈금이라 확대 쪽에서 더 세밀하게 움직입니다.
- **기본 보기** 버튼은 지금 탭의 범위를 기본값으로 되돌립니다.
- 범위와 기본값은 `js/config.js`의 `ZOOM`에서 바꿀 수 있습니다.
- 'QPM 온도' 탭의 범위는 요약 인쇄의 그래프에도 그대로 쓰입니다.

## 교차점 값 보기

모든 그래프 탭의 점 위에 마우스를 올리면(휴대폰은 탭) 값이 말풍선으로 표시됩니다.

- **QPM 온도**: 각 레이저의 동작 온도, 추천 Λ 곡선 위 0.1 nm 간격 점
- **후보 Λ 전체**: 레이저 세로선과 후보 Λ 선의 교차점 (큰 점: 추천 조합)
- **온도별 필요한 Λ**: 레이저 곡선과 후보 Λ 점선의 교차점 (큰 점: 추천 조합)
- **예시**: 가로축 범위 안의 레이저를 점선으로 그리고, 각 Λ 곡선과의 교차점을 빈 원으로 표시. Λ = 9.75 μm 곡선의 0.1 nm 간격 점에도 값이 나옵니다.
- 말풍선 내용: 레이저 이름, 펌프 파장, Λ(추천 여부), QPM 온도, 오븐 사용 온도 범위 안인지

## 예시 탭

고정된 조건으로 그린 QPM 곡선입니다. 사용한 변수는 탭 안에 목록으로 표시되며, `js/config.js`의 `EXAMPLE`에서 바꿀 수 있습니다.

- 결정·편광: PPKTP, type-II collinear (pump y, signal z, idler y), degenerate (λs = λi = 2λp)
- 펌프 파장: 403.0–404.0 nm (기본 보기), 결정 온도: 0–80 °C
- Poling period Λ: 9.65, 9.70, 9.75, 9.80, 9.85 μm
- 표시점: Λ = 9.75 μm 곡선 위 0.1 nm 간격

## 요약 인쇄

오른쪽 위 **요약 인쇄** 버튼(또는 Ctrl+P / ⌘P)을 누르면 A4 한 장짜리 요약이 인쇄됩니다.

- 잉크젯 프린터용으로 **배경은 항상 흰색**이고, 면을 채우는 색 없이 선과 글자만 씁니다 (다크 모드에서 인쇄해도 동일).
- 내용: 추천 Λ와 요약 문장, 계산 조건, 추천 Λ의 QPM 온도 그래프, 레이저별 결과표, 참고 사항, 계산 근거
- 화면에서 바꾼 값(레이저, Λ 간격, 온도 범위)이 그대로 반영되고, 인쇄 시각이 함께 찍힙니다.
- 인쇄 대화상자에서 용지는 A4, 배율은 기본값(100 %)을 권장합니다. PDF로 저장도 같은 방법으로 할 수 있습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `qpm-poling-period`, Public).
2. 이 폴더의 파일을 **저장소 맨 위(root)** 에 올립니다.
   - 웹에서: 저장소 화면의 **Add file → Upload files**에 폴더 안의 파일·폴더를 끌어다 놓고 **Commit changes**.
   - 터미널에서:
     ```bash
     git init
     git add .
     git commit -m "QPM poling period 선택기"
     git branch -M main
     git remote add origin https://github.com/<계정>/<저장소>.git
     git push -u origin main
     ```
3. 저장소의 **Settings → Pages**에서
   **Source: Deploy from a branch**, **Branch: `main` / `/ (root)`** 를 선택하고 **Save**.
4. 1–2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

> `index.html`이 `css/`, `js/` 폴더와 같은 위치에 있어야 합니다. 폴더째 한 단계 더 넣어 올리면 주소 뒤에 그 폴더 이름을 붙여야 합니다.

## 계산 요약

- QPM 조건: `1/Λ = n_y(λp,T)/λp − n_z(2λp,T)/(2λp) − n_y(2λp,T)/(2λp)` (λ는 μm)
- 굴절률: `n(λ,T) = n(λ,25°C) + (T − 25)·dn/dT(λ)`
- 후보 Λ는 설정한 간격의 배수(기본 0.75 μm → 9.00, 9.75, 10.50 …)만 검토합니다.
- 오븐 사용 온도 범위 안에서 QPM이 맞는 후보 중 선호 온도에 가장 가까운 것을 추천합니다.
- 100 °C 이상은 25 °C 근처 온도 계수를 선형으로 연장한 값이라 오차가 커질 수 있습니다.
